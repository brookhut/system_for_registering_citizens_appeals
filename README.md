# Система регистрации обращений граждан

Веб-приложение на Flask с базой данных PostgreSQL для учета, контроля сроков и обработки обращений граждан.

## Основные возможности

1. **Ролевая модель доступа**:
   - **`superadmin`**: Встроенный администратор. Логин и пароль хранятся в файле `.env`. Данная учетная запись **защищена от удаления, изменения и отключения**. Администратор управляет пользователями, наполняет справочники и настраивает зависимости между ними.
   - **`registrator`**: Регистратор обращений. Добавляет новые обращения (со статусом «В работе»), редактирует открытые обращения, отслеживает контрольные сроки и закрывает обращения.

2. **Главная страница**:
   - Вкладка **«В работе»** с актуальным счетчиком обращений.
   - Вкладка **«Закрытые обращения»** с актуальным счетчиком закрытых обращений.
   - **Поля поиска и фильтрации** над вкладками:
     - Номер обращения (поиск по фрагменту)
     - Дата регистрации (европейский формат ДД.ММ.ГГГГ, не позднее текущей даты)
     - Управление (выпадающий список)
     - Округ (выпадающий список)
     - Тип обращения (выпадающий список)
     - Тематика (выпадающий список)
     - Количество дней до ответа (просроченные, сегодня, 1-3 дня, до 7 дней, более 7 дней, без срока, точное число дней)
   - **Отображаемые столбцы**:
     - Номер обращения (с датой регистрации в европейском формате)
     - Округ
     - Управление
     - Тип обращения (с тематикой)
     - Состоит на обслуживании (Да / Нет)
     - Срок ответа в количестве дней (с цветовой индикацией остатка дней, срока сегодня или просрочки)
   - Переход в карточку обращения по клику на любую строку таблицы.
   - Кнопка **«Добавить обращение»**.

3. **Форма добавления обращения** (начальный статус «В работе»):
   - **Дата регистрации**: европейский стандарт (ДД.ММ.ГГГГ), без времени, не может быть больше текущей даты, обязательное поле.
   - **№ обращения**: указывается из внешней системы, обязательное поле.
   - **Источник поступления**: справочник superadmin, обязательное поле.
   - **Округ**: справочник superadmin, обязательное поле.
   - **Управление**: справочник superadmin, опциональное поле.
   - **Участок**: справочник superadmin, опциональное поле.
   - **Пол заявителя**: выпадающий список (мужской, женский), опциональное поле.
   - **Тип обращения**: справочник superadmin, обязательное поле.
   - **Тематика обращения**: справочник superadmin, обязательное поле.
   - **Обоснованность**: выпадающий список (обоснован, не обоснован), опциональное поле.
   - **Повторность**: выпадающий список (Первичное, Повторное, Многократное), опциональное поле.
   - **Результат рассмотрения**: справочник superadmin, опциональное поле.
   - **Контрольные сроки**: дата поступления ответа в систему (европейский стандарт).
   - **Не состоит на обслуживании**: чекбокс (влияет на колонку «Состоит на обслуживании»).
   - **Комментарий**: текстовое поле, опциональное поле.

4. **Карточка обращения и закрытие**:
   - Фиксация автора записи и даты/времени создания (`created_by`, `created_at`).
   - Кнопка **«Закрыть обращение»**: после закрытия карточка блокируется для любого редактирования, статус меняется на **«Закрыто»**, фиксируется дата закрытия (`closed_at`) и ответственный (`closed_by`).

5. **Зависимости справочников**:
   - В одно **Управление** может входить несколько **Округов**.
   - В одно **Управление** может входить несколько **Участков**.
   - Администратор может настраивать связи в разделе «Зависимости управлений».
   - На форме обращения реализована динамическая фильтрация связанных округов и участков при выборе управления.

## Переменные окружения (.env)

```env
# База данных PostgreSQL
DATABASE_URL=postgresql://postgres@localhost:5432/appeals_db
DB_HOST=localhost
DB_PORT=5432
DB_NAME=appeals_db
DB_USER=postgres
DB_PASSWORD=

# Встроенный супер-администратор (защищен от изменений в UI)
SUPERADMIN_USERNAME=superadmin
SUPERADMIN_PASSWORD=SuperAdminPass2026!
SUPERADMIN_FULL_NAME=Главный администратор

# Конфигурация Flask
SECRET_KEY=citizens-appeals-secret-key-2026-secure-token
FLASK_ENV=production
PORT=5000
```

## Установка и запуск

1. Установка зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

2. Наполнение справочников и начальных данных:
   ```bash
   python3 seed.py
   ```

3. Запуск веб-сервера:
   ```bash
   python3 run.py
   ```
   При запуске автоматически проверяется доступность порта (по умолчанию `5000` из `.env`). Если порт `5000` уже занят другим процессом, скрипт автоматически находит и занимает следующий свободный порт (`5001`, `5002` и т.д.) с выводом информационного сообщения.
   Приложение будет доступно по адресу: `http://0.0.0.0:<port>`

4. Запуск автоматических тестов:
   ```bash
   python3 -m unittest -v tests/test_app.py
   ```
